La Figura 1 muestra el modelo conceptual general de la Ontología de Servicios Públicos.

La ontología proporciona un modelo conceptual para describir servicios públicos y procedimientos administrativos ofrecidos por administraciones locales. Su objetivo es apoyar la publicación armonizada de información sobre servicios municipales, procedimientos, requisitos, documentación, organizaciones responsables e interacciones administrativas.

El modelo reutiliza y extiende el Core Public Service Vocabulary (CPSV), un vocabulario diseñado para describir servicios públicos de forma estructurada e interoperable. Siguiendo el patrón de CPSV, la ontología representa un servicio público como una actividad o función prestada por una organización pública en respuesta a las necesidades de la ciudadanía, las empresas u otros agentes. Los procedimientos administrativos se representan como procesos formales asociados al acceso, solicitud, gestión o resolución de dichos servicios.

La ontología también reutiliza elementos del Vocabulario para la representación de trámites, servicios y procedimientos administrativos ofrecidos por un ayuntamiento, que también importa CPSV y fue desarrollado para describir servicios municipales y procedimientos administrativos. En particular, esta ontología reutiliza la clase DestinadoProcedimiento para representar la entidad destinataria de un servicio público.

Los principales elementos conceptuales de la ontología incluyen:
- Servicio público: representa un servicio prestado por una administración pública, como la recogida de residuos, la atención ciudadana, los servicios urbanísticos o los servicios sociales.
- Procedimiento administrativo: representa un proceso administrativo formal mediante el cual una persona u organización interactúa con la administración, por ejemplo para presentar una solicitud, pedir una licencia, inscribir información, pagar una tasa, obtener un certificado o presentar una queja.
- Organización pública: representa el organismo, departamento o unidad administrativa responsable de prestar un servicio o gestionar un procedimiento.
- Entrada: representa la información, formularios o documentos que deben aportarse para iniciar o completar un procedimiento.
- Salida: representa el resultado producido por un procedimiento, como una autorización, licencia, certificado, resolución o inscripción registral.
- Regla: representa el marco legal, normativo o administrativo que regula la prestación de un servicio o la ejecución de un procedimiento.

Además de estas clases principales, la ontología puede complementarse con vocabularios controlados para clasificar tipos de servicios públicos y tipos de procedimientos administrativos. Estos vocabularios controlados permiten diferenciar entre el ámbito del servicio, como seguridad pública, gestión de residuos, abastecimiento de agua o mantenimiento urbano, y el tipo de interacción administrativa, como solicitud, comunicación, declaración responsable, autorización, inscripción, pago, queja o recurso.
